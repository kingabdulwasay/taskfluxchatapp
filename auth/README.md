# Signup Page (TaskFlux design)

This folder contains a standalone HTML/CSS implementation that replicates the signup design from the provided screenshot.

Files:
- `index.html` — the signup page markup
- `styles.css` — page styles, gradients and layout

Open `index.html` in your browser to view the design. Example (PowerShell):

```powershell
Start-Process .\signup_page\index.html
```
